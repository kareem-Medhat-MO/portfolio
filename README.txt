KAREEM MEDHAT PORTFOLIO — QUICK START

1) Install Visual Studio Code (VS Code), not Visual Studio.
2) Open the project folder in VS Code.
3) In VS Code, install the extension "Live Server" by Ritwick Dey.
4) Right-click index.html -> Open with Live Server.
   The website will open in your browser. Save edits (Ctrl+S) and it refreshes.

Alternative: double-click index.html to open it directly in Chrome.
The framework stylesheet, fonts, favicon, and preview image are stored locally;
the page has no required runtime CDN dependencies.

Before sharing:
- The Technical Resume and Academic CV buttons download the matching files from assets.
- Keep project details accurate and be transparent about AI-assisted work.

Project files:
- index.html contains the page content and semantic structure.
- style.css contains the visual theme, responsive layout, and decorative illustrations.
- script.js handles the mobile menu, theme switch, typing effect, and active navigation behavior.
- assets/profile-avatar.webp is the optimized portrait used in the About section; the original PNG is retained.
- assets/vendor/bootstrap.min.css is the locally bundled Bootstrap 5 stylesheet; its MIT license is in assets/vendor/LICENSE.txt.
- assets/fonts contains local DM Sans and Space Grotesk WOFF2 fonts and their SIL Open Font License notices.
- assets/icons contains the original Git, VS Code, and Visual Studio brand SVGs from Devicon; the MIT license is in assets/vendor/DEVICON-LICENSE.txt.
- assets/favicon.svg and assets/social-preview.jpg provide the local site icon and social preview.

This is a static front-end portfolio. It does not require Visual Studio, .NET, a database,
or a backend server.
